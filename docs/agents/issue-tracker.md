# Issue tracker

This project uses GitHub Issues in Dpkch06/browser-agent-routing-benchmark.

## Triage labels

Use the Ask Matt defaults:

- needs-triage
- needs-info
- ready-for-agent
- ready-for-human
- wontfix

Issues produced from the approved plan are ready for an agent. Record dependency edges in issue bodies using a "Blocked by #N" line because this tracker setup does not rely on a separate dependency extension.

## Working an issue

Read the issue and linked project docs. Work only within its acceptance criteria. Add behavior tests at the agreed seams, avoid paid API calls in routine tests, and report the commands and outcomes in the issue or pull request.
