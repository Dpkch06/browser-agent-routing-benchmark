## Direction contract

THESIS: This is a measurement workspace for browser strategy experiments. It puts every approach's outcome and usage beside the same tasks, then opens the saved report. Its visual cues describe measured state rather than imply success.

OWN-WORLD: The visual language draws from scientific data plates. Use an ice white ground, a cobalt navigation shell, ink navy text, and citron for active selection. Reserve green and red for verified outcomes. Use a clear system sans for controls and copy, tabular numerals for timing and usage, and monospace only for run identifiers. Align dense rows on a precise grid with fine rules. Add one signature move: small measurement ticks linked directly to each completed cell's result and duration. Keep tables, controls, and navigation as standard web components.

STORY: The operator sees the task and six strategies, starts one full matrix run, tracks each cell's state, then opens a saved report with outcomes and available model usage.

FIRST VIEWPORT: A cobalt top navigation names the project and shows local server status. A compact run action and task scope sit above the work area. The twelve-cell matrix leads, with clear queued, running, passed, and failed states. A saved report list follows below and opens the chosen JSON result.

FORM: Candidate three in the ordered set of seven grounded visual directions, selected for the project's measurement and comparison task. This direction was inferred from the approved project brief after the structured interview received no design preference. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
